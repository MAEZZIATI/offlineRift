- Notation table and tensor dimensions.
- Problem statement, decision-time information set and assumptions.
- Probabilistic model/objective; each equation has a stable ID.
- Estimator, optimization and training recipe.
- Explicit causal DAG, identifiability assumptions and limits.
- Key derivations, uncertainty, calibration and abstention.
- Time/memory complexity; CPU inference and Kaggle compute budget.
- Failure modes, hyperparameters and model card.
- Frozen validation gates and links to equation-referencing tests.
- Changelog: version, change, evidence, matching code/tests.

Established convention: label substantive statements established / plausible /
speculative and distinguish association, weak supervision and causal evidence.
